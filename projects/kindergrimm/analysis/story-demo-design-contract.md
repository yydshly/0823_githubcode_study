# 《风暴前的回信》故事演示设计契约

- 请求版本：1
- 目标：把 Kindergrimm 的场景、道具与样式能力放入一个有意义、可完成、可复玩的故事闭环中验证。
- 目标用户：评估素材库能力、应用价值与扩展方向的研究者、产品与内容设计者。
- 第一印象：正在经历一场暴雨前的送信行动，而不是浏览素材包或卡片目录。
- 体验等级：Immersive / Hybrid Workspace。
- 场景基础：Canvas 2D；所有图像为本地确定性程序化生成。
- 运行时大模型与云调用：0。

## 故事命题

年轻信使在洪水封城前送出一封包含公共疏散路线的回信。玩家需要点亮信标、修复路标、帮助居民，并在终点决定把路线交给少数管理者，还是公开给整个社区。主题是“信息是权力，也是责任”。

## 主要旅程

开始任务 → 接受回信与信使包 → 点亮提灯 → 修复路标 → 可选帮助居民 → 抵达旧水闸 → 解封路线 → 做出公开或私下交付的最终选择 → 查看结局 → 重玩。

## 场景与文档分工

- 持久场景：展示地点、天气、已完成行动与可交互热点；三种样式会重绘同一状态。
- 故事工作台：人物对白、任务目标、选择、库存、信任/风暴状态与结局说明。
- 移动端：场景固定在故事工作台上方，操作区保持可达，不依赖悬停。
- 降级：Canvas 不可用时保留完整文字故事、选择、库存与结局；明确隐藏图像能力边界。

## 内容范围

- 3 个章节/地点：信使驿站、山径神龛、旧水闸。
- 5 类真实道具：卷轴、信使包、提灯、路标、护符。
- 4 位叙事角色：艾萝、守站人奥伦、米娅一家、闸门管理员维斯。
- 3 种完整样式：Mosslight Gouache、Moonharbor Inkcut、Sunpatch Felt。
- 2 个可完成结局：公开鸣钟、私下交付。

## 状态到场景映射

- 初始：远处风暴、未领取回信。
- 行动：库存中的真实生成道具出现；提灯发光、路标恢复、居民被引导。
- 冲突：风暴计时减少，终点选择产生清晰权衡。
- 完成：场景和故事工作台同时进入对应结局状态。
- 恢复：可重开故事；切换样式不得丢失当前进度。

## 边界

- 本轮不声称 3D、AI 实时生成、后端账户、多人或通用游戏引擎能力。
- 外部发布、语音、3D 角色、后端存档需要用户另行授权。
- 自主授权：用户已明确要求更换为有意义、元素尽可能全面的故事并继续实现。
