# 研究项目

此目录用于存放彼此独立的研究项目。每个项目使用一个英文 slug 作为目录名，并以项目内的 `README.md` 作为该项目的完整入口。

创建新项目时，请复制 `_template/`，补全研究目标、上游版本、复现方式、结论和展示链接，然后更新仓库根目录的项目索引。

## 项目列表

- [Hands-On Large Language Models](hands-on-large-language-models/README.md)：大模型基础、应用、RAG、多模态与微调能力研究。
- [HyperFrames Launches](hyperframes-launches/README.md)：HTML 原生视频、产品发布片、WebGL、音频合成与 Agent 视频工作流研究。
