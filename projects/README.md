# 研究项目

此目录用于存放彼此独立的研究项目。每个项目使用一个英文 slug 作为目录名，并以项目内的 `README.md` 作为该项目的完整入口。

创建新项目时，请复制 `_template/`，补全研究目标、上游版本、复现方式、结论和展示链接，然后更新仓库根目录的项目索引。

## 项目列表

- [Hands-On Large Language Models](hands-on-large-language-models/README.md)：书籍驱动的大模型代码学习、13个实践与可复用研究方法。**暂时归档，后期按需学习。**
- [HyperFrames Launches](hyperframes-launches/README.md)：HeyGen 发布视频案例、素材与代码编排、HTML 网页离线渲染及 Remotion 路线对比。**暂时归档，后期按需启用。**
- [Kindergrimm](kindergrimm/README.md)：确定性童话风格的 2D、程序化 3D 与游戏场景素材研究。**第一轮研究完成，具体叙事确定后按需重启。**
