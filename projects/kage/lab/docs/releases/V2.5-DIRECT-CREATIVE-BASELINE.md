Status: **FROZEN BASELINE**  
Freeze anchor: **R125 · 冰芯来信**

## 第一目标

用户描述一个想法，Codex 在现有 Kage 项目中自主选择相关参考原理、页面结构、素材路线与互动方式，直接完成一个主题专属、具有视觉吸引力且可验证的网页。页面长度、媒介、构图与互动按内容需要决定，不继承暗色、三屏、中央主体、巨型标题或参数工作台等历史模板。

V2.5 冻结的是一套**直接创作与归档协议**，不是固定页面模板，也不是后台模型编排服务。

## 边界

- V1、旧案例库和后台生成链保持兼容，不由 V2.5 归档门追溯改写。
- V2.5 新精选必须走新的版本化归档断言；手工把链接加入页面不等于通过归档。
- 当前不建设工作台后台自动调用 Codex，不接入 MiniMax 路由、Figma 或新模型供应商。
- 当前不批量重做旧案例，也不继续收集无限参考库。
- content-fit 门当前明确检查“无内容依据的持久单舞台参数工作台”这一已证实惯性；它不伪装成对所有页面结构的万能审美判断。

## 验证入口

```powershell
npm.cmd run verify:v2.5
```

该命令只覆盖冻结基线所需的协议、归档、R125 身份、V2 首页和代表性旧/新案例；它不是全仓库无限回归。

冻结时实际验证：

- `npx tsc --noEmit`：通过。
- `npm.cmd run build`：通过。
- `npm.cmd run build:pages`：通过；仅保留既有的绝对素材解析提示与 chunk 体积提示。
- V2.5 定向 Vitest：协议、参考、结构、身份、归档和 R125 证据全部通过。
- V2.5 定向 Playwright：18 / 18 通过，覆盖 V2 首页、390px、旧工作台漂移阻断、纸蝶对象场、R123 织造互动和 R125 桌面/滚动/信件/移动/fallback。
- Canonical runtime：`npm.cmd run dev -- --host 127.0.0.1 --port 8143`；V2 URL：`http://127.0.0.1:8143/pages/v2/`。

## 冻结后的使用方式

后续新目标从 V2 页面生成并复制 `DirectCreativeAuthorPackage v2`，直接交给 Codex 在现有项目中创作。只有最终结果满足版本化归档断言时才登记为新的 V2.5 精选；未达标结果诚实停止为研究记录，不追加候选、不循环修图。
