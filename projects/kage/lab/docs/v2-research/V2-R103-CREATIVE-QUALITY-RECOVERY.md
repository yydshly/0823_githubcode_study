# V2 R103 — 创意质量恢复与有界生成

## 设计契约

- Entry mode：revision-led；R102 证明运行链可用但视觉交付失败，本轮修订生成目标与质量路由。
- Target user：在工作台输入一个想法、希望直接获得具有主题辨识度、创意与产品闭环的优秀网页的人。
- Desired first impression：不是模板、示意图或技术样本，而是十秒内能辨认主题、审美方向和核心体验的完整作品。
- Visual ambition / architecture：由 brief 决定 Editorial、Immersive 或 Hybrid Workspace；不预设暗色电影页、纸白信息页、固定三屏、Three.js 或 Canvas。
- Primary journey：想法 → 2–3 个低成本创意方向 → 选定一个正向视觉合同与素材职责 → Codex 构建一个主候选 → 功能门与独立视觉门 → 精选、研究或淘汰。
- Visual constraints：素材、渲染和模型来源不设先验禁令；选择必须服务最终画面质量、主题连续性和业务结果。程序化、真实素材、模型生图、3D、视频与 DOM 均可组合。
- Quality boundary：需要丰富材质、真实主体或空间证据的主视觉，不能以零素材低保真 Canvas 自动视为 L3；纯程序化路线只有在浏览器独立视觉证据达到作品级门槛时才可晋级。
- Operation constraints：创意方向只做轻量决策，不生成三个完整页面；只构建一个主候选；最多一次证据驱动整体精修；不无限重试。
- Supported surfaces：桌面主视口、390px 手机、键盘/触摸等价路径、reduced-motion、增强能力失败时的可读 fallback。
- Autonomy authorization：用户已明确“持续推进”，允许在现有 V2 架构内执行可逆代码、测试、生成和浏览器验收，不重复询问。
- User-decision boundary：仅外部发布、付费素材或真实业务数据需要新授权；内部方向选择、测试主题和可逆实现由 Codex 决定。

## 可观察完成标准

1. 生成链不再直接使用 `candidates[0]` 冒充“最佳方向”，而是留下可解释的方向选择证据。
2. 素材来源排序不等于质量结论；候选以真实质量证据晋级，不因来源名称自动判定优秀或低质。
3. 零外部素材的程序化作品只有在独立视觉分数、主体角色、产品状态和无重大缺陷同时达标后才可成为最终结果。
4. `deliveryQuality.finalEligible=false` 的任务不能标记为 `complete` 或进入精选案例。
5. 使用一个未重复主题完成单候选验证；若未达作品门，明确淘汰并停止，不以机械通过替代视觉成功。

## 停止规则

- 不继续精修 R102 植物叶片页面；它保留为“技术通过、视觉失败”的反例。
- 新验证只允许一个完整构建和一次精修；仍不达标即停止并记录根因。
- 不把新增能力、素材数量、测试数量或模型调用次数当作阶段成功；阶段成功只由最终作品质量与可复现证据决定。

## 单主题验证结论

- 测试主题：独立书店日光选书桌；拖动或滚动情绪纸带，书封、引文卡与阅读路径重排，终点生成选书单。
- 单次生成：`gpt-5.6-sol`，1 次 authoring，4 个源码文件，22,328 bytes，0 个外部素材。
- 时间：本地规划 73ms、素材路由 51ms、模型创作 108,841ms、浏览器初检 10,083ms。主要耗时在唯一一次 Sol 代码生成，不在本地规划。
- 初始问题：不透明页面根层遮住 SDK Canvas；一次确定性遮挡修复与一次真实 Canvas anchor 修复后，机械门达到 100。
- 独立视觉结论：`revise / 76`。四个 major 分别为固定三段结构、终态主体消失、终态构图空泛、交互因果弱；另有首屏焦点竞争和移动端终点留白两个 minor。
- 决策：不进入精选案例库，不继续修复该 run。它只作为“机械通过不等于优秀作品”的研究证据。

## 由失败反推的系统修复

1. “纸张/排版”不再单独触发材质变形或声音排版场；互动策展/选书任务改走编辑式聚焦工作区。
2. `continuous-canvas` 优先选择 focused candidate，不能被冲突的风格标签推成 guided journey。
3. continuous-canvas 执行包强制 opening / middle / final 保留同一视觉主体，禁止不透明三段屏，终点必须可视化业务结果。
4. 独立视觉通过但缺少 `deliveryQuality` 时按 fail-closed 保留为 `review-required`。

## 下一阶段边界

- 不再重跑或精修书店候选。
- 下一次验证只允许一个未使用主题、一个主候选、一次独立视觉门；通过才归档，失败则记录并停止。
- 素材来源保持开放，但进入运行时前必须本地化并留下质量与来源证据；这属于可复现和安全边界，不是审美来源限制。
