# Kage V2/V3 · R135 项目状态与收口路线

## 第一目标

把普通用户的一段想法，转译为主题专属、视觉优秀、具有创意与合适互动、可运行且可验证的网页。案例、素材、Three.js、WebGL 和代码都是为效果服务的可选手段，不是默认答案；产品不是固定三屏、暗色科技或工作台模板。

## 当前架构

```text
Brief
→ CreativeInstruction（用户硬要求 / 质量门 / 参考建议 / 推断建议）
→ ReferenceEvidencePack（相关优秀案例与可借原理）
→ CreativeContract / ExperienceDirector
→ CreativeMediumDecision + VisualAmbition
→ V3 AuthorPackage / DirectCreativeRun
→ Codex 在现有项目内有界实现
→ 自适应浏览器证据 + WowGate
→ runId + bundleHash + 媒介一致性归档
```

## 已实现能力

- 用户要求与通用质量门可作为硬约束；案例和模型推断只作为建议。
- 已有生成图、真实媒体、Three.js 空间、程序化 WebGL、代码原生五种媒介决策路线。
- 已有素材职责、运行时、互动、移动端、reduced-motion、fallback、音频和最终身份校验。
- 最终证据可绑定 `runId + bundleHash`；修订后旧截图不能代表新 bundle。
- V2.5 已有多种结构的历史精选，R134 是第一个通过独立 V3 归档门的完整 WebGL 案例。

## 客观差距

- 工程架构完成度约 85%；按“普通想法稳定得到优秀成品”的产品证据衡量约 65%。这两个百分比是阶段评估，不是自动评分。
- V3 端到端媒介闭环目前为 `2/5`：R134 程序化 WebGL，R135 生成主视觉 + WebGL 动态增强。
- 不含技术提示的普通 brief，自主选对媒介并产出精选结果：1 个（R135）。
- V3“高质量主素材 + 运行时动态增强”闭环：1 个（R135）。
- 已有 1 组首次预览与完整耗时证据：约 7 分钟到首次预览、20 分 20 秒完成全部实现与验收。
- 近期差异案例尚未全部回灌为正向参考；内部视觉评分也仍需和用户对“模板化、素材差、没有感觉”的反馈校准。
- 首页展示仍混用 protocol V2、V2.5 与 V3 表述；项目也需要形成可恢复的版本基线。

## R135 阶段结论

- 已完成且停止：普通想法没有指定技术，系统仍自主选择了适合主题的高质量生成主视觉，并让 WebGL 只承担真实动态增强。
- 最终结果通过 Quality `94`、Wow `93`、5 个浏览器场景、V3 身份绑定、页面构建和 155 项 V2.5 回归测试。
- 这证明“素材决定环境与第一记忆点、代码决定输入因果与完成状态”的路线可行，也修正了此前用本地代码图形冒充关键主体的偏差。
- R135 不继续修图、不追加素材、不增加第二结构；项目进入 R136。

## 三阶段路线

### R135 · 无技术提示的混合媒介验证（已完成）

- 一个普通新想法，由系统自主选择生成主视觉和动态增强。
- 一张高质量主图、一批素材、一次构建、最多两次确定性修复、最多一次视觉精修。
- 主图字节进入 hash；滚轮或指针改变至少两个非 DOM 视觉变量；桌面、390px、reduced-motion、WebGL/素材回退均通过。
- 记录首次预览和总耗时；未达质量门则停止为研究结果。

### R136 · 跨路线复现与正向参考回灌（下一阶段）

- 将 R128–R135 的目录、分支、声音、横向全景、程序化光场与混合媒介经验整理为高可信 evidence packs。
- 再用两个无技术提示 brief，顺序验证两条不同的媒介与宏观结构。
- 完成标准：2/2 内容适配，结构与媒介不同，无第二素材批次；连同 R134 达到至少三种 V3 路线与三种宏观结构。

### R137 · V3 产品与发布收口

- 统一 Composer、首页和归档状态，清楚区分 legacy showcase 与 identity-bound verified。
- 固化耗时、尝试次数与停止原因；完成定向测试、构建和自适应浏览器回归。
- V3 registry 至少三条，并为 Kage V2/V3 建立可恢复提交基线。

## 当前动作与停止点

R135 已完成并停止。下一步只执行 R136：先把近期有效经验整理为可检索的正向参考证据，再用两个未出现过、没有技术提示的普通想法验证两条不同媒介路线与两种不同宏观结构。每个想法仍采用一次素材批次、一次构建、最多两次确定性修复和一次视觉精修；未达质量门就诚实停止，不进入精选库。

R136 完成后进入 R137，统一 V3 首页、Composer、归档口径、耗时与停止证据，并形成可恢复版本基线。到 R137 验收通过，本轮“从自由探索到有依据、有边界、可验证的创意生成产品”才算阶段性完成。
