# V2 R78 · 候鸟风洞演示与滚轮驱动精修

## 设计契约

- 进入方式：repair-led，直接精修 R77 当前页面，不启动新的模型生成任务。
- 请求修订：R78。
- 目标用户与情境：学生或普通访客首次打开纸翼候鸟风洞教学模拟。
- 首屏感受：不用猜测如何操作；点击演示或滚动页面即可立即看到条件、数值与风洞画面发生有因果关系的变化。
- 视觉目标：Immersive。
- 体验架构：Spatial Stage；Canvas 风洞保持为主要操作表面，控制与结果作为同屏前景层。
- 保留：现有明亮风洞视觉、三个参数、对比轨迹、结果说明与保存动作。
- 不引入：新候选、外部素材、模型调用、后端流程或无限精修循环。
- 主要旅程：进入页面 → 点击“播放演示”或向下滚动 → 参数与风洞同步变化 → 暂停/重置或继续手动调节 → 保存观察。
- 支持边界：桌面滚轮与按钮完整支持；窄屏保留按钮和直接参数操作；reduced-motion 使用离散状态，不播放连续自动动画。
- 自主授权：用户已明确“确定”并要求继续实现演示触发和滚轮驱动。
- 用户决策边界：本轮没有需要新增授权的产品决策。

## 可观察完成标准

1. 页面存在明确的播放/暂停与重置入口，并显示当前驱动来源和进度。
2. 播放演示会在一段有界时间内驱动风速、侧风、翼角、结果文本和 Canvas 画面；结束后停止。
3. 真实页面滚动会接管驱动，并连续映射到同一组参数和画面；手动滑块仍可接管。
4. 候鸟姿态、飞行高度、翼面轮廓、气流与主轨迹均具有可见变化，而不是仅改变小字数值。
5. 桌面、窄屏、键盘按钮与 reduced-motion 路径可用；无水平溢出和遮挡。
6. 只完成这一轮交互精修和验收，不继续自动生成或重复修复。
