# V2 可折叠露营灯有界验证 R64

## 目标与边界

用一个未使用过、具有明确实体状态变化的主题验证现有主链路，而不是继续修 R62：

`想法 -> V2 合同 -> 状态素材路由 -> Codex authoring -> 主体差异门禁 -> 独立视觉判断 -> 归档或停止`

- 主题：同一盏可折叠日光露营灯由扁平收纳、部分展开、完全展开到暖光点亮。
- Selected pattern: Product case + DOM/media state narrative。
- Existing architecture: 复用工作台、项目素材目录、Codex 5.6-sol、浏览器机械审计和独立视觉判断。
- Stop boundary: 一个候选、一次正式验收；不创建第二主题，不在超时后继续调用模型。

## 素材证据

- 使用内置 ChatGPT 图片生成能力生成一张 2×2 同机位状态母图。
- 项目文件：`public/creative-assets/r64-collapsible-lantern-four-state-v1.png`，约 1.74 MB。
- 素材级别：`L3-presentable`；适合网页中远景和状态序列，不冒充可自由旋转的 L4 真实模型。
- 连续性证据：同一提手、顶盖、铝环、象牙色折叠灯罩、底座、自然光和接地阴影跨四状态保持一致。
- 素材登记：`collapsible-lantern-four-state-v1`，`sequence / 4 states / 3 part groups`。
- 路由结果：项目目录命中 1 个 L3 素材，跳过 MiniMax；没有让 Codex 用程序化占位物重建产品。

图片生成最终规范：高端真实产品摄影；2×2 等分状态表；同一无品牌折叠露营灯、同一机位和比例；依次为扁平、部分展开、完全展开、暖光点亮；自然日光、暖白背景；禁止文字、商标、人物、暗色科技风、紫色、粒子、不同产品和不可能形变。
