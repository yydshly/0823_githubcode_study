# V2 R144 · 多媒介创意编排与意境档案

## 目标

在不改写 V1、现有 V2 运行时、案例 API 和有界执行协议的前提下，让 Codex 不再把“首选媒介”误解为“唯一媒介”。一次创作仍只选择一个创意方向，但可以由一个主导媒介和最多三个有明确职责的辅助媒介共同完成最终效果。

同时，把已经通过浏览器验证、具有意境或多媒介研究价值的 V2 页面沉淀为独立研究档案。研究档案用于后续参考与回顾，不自动获得“精选案例”资格。

## 设计契约

- 视觉目标：首屏有主题专属记忆点，素材、3D、声音、视频、动效和排版按内容需要组合，而不是按技术清单堆砌。
- 硬约束：只有当前用户硬要求和项目质量门可以阻断创作；案例经验和媒介建议均为建议。
- 素材边界：默认 `open-best-fit`，允许真实素材、已有素材、生成素材与程序化渲染；事实内容必须保留真实性边界。
- 运行边界：一个创意方向、一次素材批次、一次完整构建、最多两次确定性修复和一次视觉精修。
- 兼容边界：不接后台 Codex、不增加供应商、不重做 V1、不批量重做旧案例。

## 完成标准

1. `CreativeDirectionSpec` 明确主导媒介、辅助媒介职责、参考融合、优秀轴、失败信号和开放素材策略。
2. 作者提示不再声明首选媒介为唯一媒介；失败回退仍保持有界。
3. 案例页展示至少八个已验证意境案例，并明确标记为研究参考而非精选。
4. 所有档案预览来自对应最终交付的浏览器证据，入口可访问，移动端无阻断溢出。
5. 类型检查、目标单测和真实浏览器检查通过。

## 验收结论

- `npx tsc --noEmit`：通过。
