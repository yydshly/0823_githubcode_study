# V2 R130 · 全新想法决策链证明

## 阶段目标

本阶段不再增加相似精选案例，也不建设后台 Codex 调用。目标是证明现有 V2.5 能在编码前，把一个从未使用过的想法转换为自洽的创作决策：正确结构、正向参考、素材职责、互动价值、媒介强度和有界验收必须来自同一份合同。

## 已观察到的断点

- 普通“路线”会被误判为真实地理地图，进而污染素材真实性与视觉锚点。
- 任意程序化主体会被泛化为 Canvas Shader，随后又被描述成 WebGL、体积空间，即使最终实现只是 SVG + 可选 Canvas 2D。
- 精简作者包丢失目标回放、素材职责和完整方向理由，导致 R127–R129 的 finalizer 系统性手工改写。
- “为某个主题设计”会被误读为受众。
- 对象探索计划没有同步覆盖 styleDiversity，最终导演输入、互动验收可能互相矛盾。

## 本阶段范围

1. 收紧地图与真实地域证据触发：路线必须与地点事实、地图、站点、导航或距离等证据共同出现。
2. 让 branching-confluence 和非 3D object-field 优先选择语义 DOM + SVG/CSS；Canvas 2D 只能作为可选增强，不能自动升级为 Shader/体积空间。
3. 精简作者包必须保留 goal、完整 direction 摘要、references 和 assets 的视觉职责、连续性、可见证明与回退。
4. 修正受众解析和对象场的交互结构对齐。
5. 用“儿童自然博物馆·森林声音路线”全新 brief 做一次只到作者包的决策证明；不在本阶段生成并精修新页面。

## 非目标

- 不修改 V1、案例库运行时、模型供应商或工作台后台调用。
- 不批量重做历史案例。
- 不为通过测试强塞低相关参考；零个高相关参考必须被如实记录。
- 不进行无限素材生成或视觉精修。

## 验收标准

- R129 分支汇合：不是地图，不要求真实地理；primary medium 为 SVG，depth 为 layered-2d，credibility 为 conceptual-coherent。
- 城市公共饮水点：仍选择真实地理地图与 data-grounded。
- 既有连续空间旅程：仍保留原来的 continuous-canvas / continuous-stage 路由，不被本次对象场规则覆盖。
- 全新森林声音 brief：选择 object-field / pointer，识别点击后的可见与可听反馈，音频验收为 applicable；不生成地图、产品英雄或持久工作台。
- Author package 直接包含目标、方向理由和完整素材职责，序列化仍小于 30KB。
- V2 单元回归与页面构建通过；本阶段没有静默重试。

## 停止条件

完成上述确定性修复与回归即停止。若全新 brief 仍需新增独立体验模式，记录为下一阶段产品能力缺口，本阶段不再扩写页面或素材。

## 最终结果

- 全新 brief 得到 `single-scene / object-field / pointer`，不再串成地图、产品英雄或持久工作台。
- 主媒介为 `svg`，空间声明为 `layered-2d`，素材可信度为 `conceptual-coherent`；没有再误报 WebGL Shader、体积光或真实地理。
- 点击后的视觉因果和自然声音播放均被识别；DirectCreativeRun 验收种子为 `direct + audioApplicable`。
- 作者包包含 goal、完整方向理由和素材责任/连续性/可见证明，序列化为 15,330 bytes；零次静默重试。
- 当前没有高相关度参考证据包，因此如实保留空引用，不用低相关案例凑数。该能力缺口留给下一阶段按需补齐。
- 证明记录：`docs/v2-research/evidence/r130-unseen-decision-proof.json`。

阶段结论：**通过并停止**。本阶段只证明“编码前决策链自洽”，未生成新页面，也未把研究结果加入精选案例库。
