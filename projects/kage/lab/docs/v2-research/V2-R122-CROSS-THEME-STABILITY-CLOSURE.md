# V2 R122 · 跨主题稳定性闭环

## 阶段目标

R122 不新增主题、不修改 R120 纸蝶交付，也不扩大生成协议。它只关闭 R120/R121 已登记的两类工程债务：同一 bundle 并发发布时的构建报告竞态，以及五项跨主题合同回归。

## 已关闭问题

1. **并发发布竞态（2 项）**
   - 同一 bundle ID 的并发构建曾共享 staging 目录，导致一条任务删除另一条任务仍需读取的 `build-report.json`。
   - staging 改为每次构建唯一目录，并按最终 run 目录串行发布。
   - 新增同 ID 并发物化回归，最终地址只暴露完整 bundle 与完整构建报告。

2. **植物观察路由（2 项）**
   - 植物 brief 中的“证据”曾抢先命中通用编辑档案路由，丢失标本主体与必需素材。
   - 高特异性的植物观察路由现在先于通用“档案/证据”分支判定。

3. **阳台晾晒误判地图（1 项）**
   - “城市 + 位置”过宽，会把固定晾衣位置误判为地理决策。
   - 地图 fallback 不再把泛化“位置”当作充分证据；明确地图、站点、路线、距离、位置选择等能力仍保留。

4. **档案结构断言（1 项）**
   - 生产合同已明确使用内容自适应的 `editorial-flow`，旧测试仍期待 `guided-sequence`。
   - 测试更新为当前产品语义；没有把档案页面改回固定节点结构。

5. **榫卯状态素材（1 项）**
   - 连续状态策略只有 `state-subject` 时，旧工作台环境没有可选承载位。
   - 状态变化仍只由 required `state-subject` 证明；缺少环境时补充 optional `spatial-environment`，普通编辑页面不会被动增加环境素材。

## 验证结果

- 四个原失败分组：`43/43 passed`。
- dedicated 并发物化：`35/35 passed`。
- 相邻 V2 路由与执行合同：`17/17 passed`。
- 修复后定向复核：`52/52 passed`。
- 完整矩阵：`97 files / 524 tests passed`。
- `tsc --noEmit`：通过。
- production Vite build：通过；仅保留既有的大 chunk 提醒。

## 影响边界与停止原因

- R120 的 `runId`、`bundleHash`、页面源码、素材、浏览器证据和案例入口均未改变。
- R121 的最终 Beta 候选与案例归档未改变。
- 没有新增供应商、没有重新生成素材、没有启动视觉精修、没有批量重做旧案例。
- 两个既有债务簇已被测试和生产构建共同关闭，因此本阶段在此停止；继续增加修补将超出本阶段目标。

## 项目当前结论

V2 当前已具备：内容自适应创意合同、正向参考输入、有界 Codex 创作、状态/场景素材门、真实交互验证、最终身份绑定和案例归档。下一阶段应回到第一目标，用一个新的未使用主题验证“参考启发 + 高视觉吸引力 + 主题专属互动”的端到端质量，而不是继续修复本轮已关闭的旧断言。
