# R05 · MotionSites 首批研究沉淀与创意组合

日期：2026-08-27  
状态：首批完成；不代表全站研究完成。

## 这一轮解决什么

V1 的主要问题不是模型能力不足，而是模型收到的自由空间过大：

```text
一个宏观想法
  -> 模型自行选择视觉方向、素材、技术和交互
  -> 多轮探索与返工
  -> 耗时长，质量和可解释性不稳定
```

R05 把 MotionSites 研究从零散案例说明扩展为一个可持续系统：

```text
公开目录元数据
  -> 案例研究清单（E1）
公开教程或完整规格
  -> 候选原理（E2 / E3）
Kage 本地原型与浏览器证据
  -> 已验证原理（E4）
兼容性检查
  -> 创意组合配方
V2 选择器
  -> 只使用证据足够且与目标匹配的能力
```

## 覆盖事实

- MotionSites 公开目录在 2026-08-27 返回 462 条记录。
- 本轮结构化 34 条首批样本：20 条整页 / Hero 方向，14 条 Sections 局部组件方向。
- 证据分布：32 条 E1、1 条 E2、1 条 E3。
- E1 条目没有填写实现事实，只保留公开标题、分类、访问状态、预览类型、研究信号和下一证据问题。
- `Scroll Landing Page` 具有公开完整规格；`Pulse 3D` 只有案例元数据与官方通用 3D 教程，不能把通用教程冒充成案例自身实现。

数据位置：`src/v2/motionsites-research.ts`。

## 沉淀结果

### 1. 案例层

案例层只回答：

- 它属于哪个页面或组件方向；
- 当前证据等级是什么；
- 已确认什么；
- 下一步必须观察什么。

它不直接成为模板，也不允许模型从缩略图猜技术栈。

### 2. 原理层

首批形成 13 个原理原子：

- E4 已验证：全屏连续媒体场、语义 DOM 独立层、全局滚动时间轴、减少动态稳定状态；
- E3 候选：媒体就绪分层、编辑式主体安全区、局部缺陷精修；
- E2 候选：固定视口 GLB 滚动、多视图 GLB 门槛、色调映射产品灯光；
- E1 研究目标：交互即信息、局部响应组件、自由指针导航。

原理描述实现职责和验收，不包含固定颜色、字体、区块数量或某个案例的视觉外壳。

### 3. 创意组合层

首批形成四个组合：

| 组合 | 证据 | 当前状态 | 意义 |
| --- | --- | --- | --- |
| 编辑式记忆场 | E4 | 已验证 | 可直接支持梦境、环境记忆和连续状态 brief |
| 资产主导的发布序列 | E3 | 候选 | 适合时装、艺术、单主体产品；需远端媒体验证 |
| 产品空间揭示 | E2 | 候选 | 适合真实产品、拆解、材质与空间关系；需 L3+ GLB 原型 |
| 编辑式交互发现 | E1 | 研究目标 | 需要桌面、键盘、触屏与减少动态的运行证据 |

组合遵守两个硬规则：

1. 任何组合的可信度不高于其中最低证据；
2. `global-scroll-timeline` 与 `free-pointer-navigation` 等职责冲突的原理会被程序拒绝。

这让模型仍能创造新的页面，但创造发生在明确的职责、证据和禁区之内。

## 可见研究页

新增独立入口：`/pages/v2/research/`。

页面支持：

- 按公开目录 / Sections、能力簇和证据等级筛选；
- 查看每个案例的已知事实、研究信号、禁止推断项和下一证据；
- 查看 13 个原理原子的来源、状态和验收；
- 查看四个创意组合的互补理由、证据上限和防误用规则；
- 从 V2 Composer 导航直接进入研究页，并可返回创意契约。

研究页不加载 MotionSites 的预览图片或视频，避免把外部视觉复制进 Kage，也避免研究页依赖第三方媒体可用性。

## 下一研究单元

下一步只验证一个问题：`product-spatial-reveal` 能否从 E2 升到 E4。

最小范围：

1. 一个达到 L3 或以上的项目可用 GLB；
2. opening / middle / ending 三个可复现滚动状态；
3. 相机、灯光、色调映射和语义 DOM 的明确职责；
4. 390px 移动回退与 `prefers-reduced-motion`；
5. 资产请求、载荷、帧率和浏览器截图证据；
6. 失败时拒绝进入 V2 选择器，不用程序化几何静默代替真实产品。

完成这一个闭环后，再回到目录选择第三种明显不同的路线，而不是并行堆积更多未验证能力。
