CH 11 · FINE-TUNING BERT

冻结层，就能保证训练得更好吗？

770 → 2271万可训练参数；训练batch均100%
先预测

只训练分类头、最后一层加分类头、全量训练时，梯度和参数更新会分别出现在哪里？

动手

不下载BERT或MPNet；固定已有MiniLM、8条文本和5步训练，只改变可训练范围。

观察

可训练参数770、1,775,234、22,713,986；对应位置确实更新，三者都把训练batch拟合到100%，额外训练状态估算为0.009、20.316、259.941MiB。

解释

冻结控制更新范围与成本，不直接保证质量；整句分类输出[2,2]，NER则为每个Token输出[2,7,9]，都需要独立验证集。

04 / SYNTHESIS

把十三个实践，压成一条判断链。

以后研究任何AI仓库，都不要先问“用了什么模型”。先顺着数据、转换、目标、决策与指标、失败边界，找到真正承担能力的代码。

  1. 01数据实际输入、标签与切分
  2. 02转换表示、状态或参数变化
  3. 03目标代码真正奖励什么
  4. 04决策与指标怎样变成答案并验收
  5. 05失败边界哪些结论还不能推出
01
LAB 01 · CH 02

输入编码

STRING → TOKEN IDS
数据
中英文本、emoji、大小写、数字
转换
Tokenizer映射到词表Token ID
目标
检查切分与上下文占用，不训练
决策与指标
Token序列、长度和拆分差异
失败边界
Token更少不等于语义、知识或推理更好。
02
LAB 02—04 · CH 01 / 03

逐Token生成

LOGITS → TOKEN
数据
提示Token与已生成历史
转换
Causal LM输出logits；KV Cache保存历史计算
目标
下一Token概率与增量计算链路
决策与指标
argmax/采样、重复度、延迟和内存
失败边界
能生成不等于正确有用；缓存提速不提升知识。
03
LAB 05—06 · CH 04 / 05

向量判别与结构发现

VECTOR → LABEL / CLUSTER
数据
带标签影评或无标签论文
转换
Embedding接分类器、UMAP与HDBSCAN
目标
学习判别边界或密度结构
决策与指标
F1、混淆、ARI、离群率与文档核查
失败边界
相同向量可产生不同决策；关键词不是主题真相。
04
LAB 07—08 · CH 06 / 07

提示与工具执行

PROMPT → ACTION TRACE
数据
规则、示例、Schema、工具与观察
转换
提示约束生成；执行器完成确定性操作
目标
格式遵循与调用—观察—回答闭环
决策与指标
字段、调用、观察采用、最终答案与轨迹
失败边界
工具算对不代表模型采用或最终回答正确。

LAB 09—10 · CH 08 / 09

决策与指标
Recall@k、Top-1、间隔与拒答
失败边界
最相似不等于有答案或为真；漏召回后无法重排回来。
