# Claude of Tanks Pages media

This directory mixes two clearly separated evidence classes:

- `*.webp` files are presentation media published by the upstream Claude of Tanks project and fixed here against upstream revision `fba54d06a5ccf1053477efde5e60bb9b338584e9`.
- `local-home.png`, `local-mobile-portrait.png`, `capability-showcase-hero.png`, and `archive-*.png` are browser evidence captured by this research project.

Upstream media remains subject to the upstream repository's `LICENSE`, `NOTICE`, and attribution files. Local screenshots document runtime behavior and do not transfer ownership of the depicted upstream implementation.

The deployed Phase 01 pages deliberately label upstream media and local evidence separately.
